📋 셀라앙상블 찬양단 - 빠른 업데이트 가이드

🎯 현재 수정된 파일: music.html (음악 업로드 기능)

🚀 서버 업데이트 방법:

1️⃣ FTP 업로드 (가장 일반적)
   - FileZilla 다운로드: https://filezilla-project.org/
   - 서버 정보 입력 (호스팅 제공업체에서 받은 정보)
   - music.html 파일 업로드
   - 서버 재시작

2️⃣ 웹 호스팅 제어판
   - 호스팅 제어판 로그인
   - 파일 관리자 → music.html 업로드
   - 서비스 재시작

3️⃣ 로컬 테스트
   - deploy.bat 실행
   - 또는: taskkill /f /im python.exe && python app.py

✅ 업데이트 후 확인사항:
   - 웹사이트 접속: http://localhost:5000
   - 관리자 계정으로 로그인
   - 음악 페이지에서 업로드 기능 확인

⚠️ 주의사항:
   - 업데이트 전 백업 필수
   - data/ 폴더는 보존
   - 브라우저 캐시 삭제

📞 문제 발생시:
   - 호스팅 제공업체 고객센터
   - 서버 관리자 연락
