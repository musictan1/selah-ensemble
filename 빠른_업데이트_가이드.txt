📋 셀라앙상블 찬양단 - 빠른 업데이트 가이드 (오늘 방식)

🎯 현재 설정:
- 서비스: Render.com
- URL: https://selah-ensemble.onrender.com
- 자동 배포: 활성화됨

🚀 업데이트 방법 (오늘 방식):

1️⃣ 코드 수정
   - 로컬에서 파일 수정 (music.html, app.py 등)
   - python app.py로 로컬 테스트

2️⃣ GitHub 업로드
   - github_deploy.bat 실행
   - 커밋 메시지 입력 (또는 Enter)
   - 자동으로 GitHub 푸시

3️⃣ Render.com 배포 확인
   - https://render.com 접속
   - selah-ensemble 프로젝트 클릭
   - "Deploy live" 상태 확인 (초록색 체크마크)

4️⃣ 웹사이트 확인
   - https://selah-ensemble.onrender.com 접속
   - 업데이트된 기능 테스트
   - 모바일에서도 확인

✅ 성공 확인:
- Render.com에서 "Deploy live" 상태
- 웹사이트에서 기능 정상 작동
- 모바일에서도 정상 작동

⚠️ 주의사항:
- 무료 인스턴스는 비활성 시 스핀다운됨
- 첫 접속 시 50초 대기 필요
- 로컬에서 먼저 테스트 필수

📞 문제 발생시:
- Render.com 대시보드에서 로그 확인
- 로컬에서 python app.py로 테스트
- GitHub 저장소에서 커밋 히스토리 확인
