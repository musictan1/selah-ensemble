🔍 Google Search Console 등록 가이드

1단계: Google Search Console 접속

Google Search Console에 접속하여 Google 계정으로 로그인합니다.

2단계: 사이트 등록

"URL 접두어"를 선택하고 사이트 URL을 입력합니다:

https://your-domain.com

⚠️ your-domain.com 부분을 실제 도메인으로 변경하세요!

3단계: 소유권 확인

HTML 태그 방식을 선택하면 다음과 같은 메타 태그가 제공됩니다:

<meta name="google-site-verification" content="YOUR_VERIFICATION_CODE">

이 코드를 index.html의 <head> 섹션에 추가하세요.

4단계: 사이트맵 제출

등록이 완료되면 "사이트맵" 메뉴에서 다음 URL을 제출하세요:

https://your-domain.com/sitemap.xml

⚠️ 중요 사항

  • 모든 URL에서 your-domain.com을 실제 도메인으로 변경해야 합니다.
  • Google Search Console에서 제공하는 실제 인증 코드를 사용하세요.
  • 사이트맵 제출 후 검색엔진에 색인이 생성되는 데 몇 주가 걸릴 수 있습니다.

추가 SEO 최적화 팁

  1. 콘텐츠 품질: 고품질의 원본 콘텐츠를 정기적으로 업데이트
  2. 페이지 속도: 이미지 최적화 및 코드 최적화
  3. 모바일 친화성: 반응형 디자인 확인
  4. 내부 링크: 페이지 간 자연스러운 링크 구조
  5. 로컬 SEO: 지역 정보가 있다면 Google My Business 등록

5단계: 네이버 서치어드바이저 등록

네이버 서치어드바이저에서도 동일한 과정으로 사이트를 등록하세요.

네이버에서도 사이트맵을 제출하면 검색 노출이 향상됩니다.

이 페이지는 Google Search Console 등록 후 삭제해도 됩니다.
